# Team Afterburner — DS5006 Final Submission

This package groups the report, report LaTeX source, project code, AI-use log, and presentation deck.

## Contents
- `report.pdf`: final report. references, contribution statement, AI-use summary and appendices are excluded from the limit.
- `report_src/`: LaTeX source and all report figures.
- `code/`: experiment notebooks, helper code, `README.md`, `requirements.txt`, and `run.py` entry point.
- `AI_USE_LOG.md`: team AI-use log, including Rajorshi Adhikary's Entry 005.
- `presentation/`: final presentation deck and its available PDF/LaTeX source files.

See `code/README.md`. The NASA C-MAPSS datasets are not bundled; obtain them separately and configure notebook data paths before running.
